# Chinese Recipe Collection

This project is a simple static website that showcases six popular Chinese-inspired recipes. Each recipe has its own HTML page with ingredients, step-by-step instructions, and an image.

## Project Overview

The site includes:

- A main landing page with links to all recipes
- Individual recipe pages for each dish
- Images for each recipe in the `recipes/images` folder
- Simple HTML-only structure with no external frameworks

## How to Run

1. Open the project folder in a browser.
2. Open `index.html` to view the recipe list.
3. Click any recipe link to view the ingredients and method.

You can also use a local web server if needed, but the site works as a static HTML page.

## Technologies Used

- HTML
- CSS not required for this version
- Image assets in `.jfif` format

## Notes

This is a beginner-friendly recipe website made to practice basic HTML structure, links, and page organization.
